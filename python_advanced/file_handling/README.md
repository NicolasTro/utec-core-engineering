# Python - Manejo de archivos

Este directorio contiene ejercicios prácticos sobre manejo y manipulación de archivos en Python:
- `read_file.py`: Lee un archivo de texto con codificación UTF-8 y lo imprime en `stdout`.
- `write_file.py`: Escribe una cadena de texto en un archivo UTF-8 (sobrescribe o crea) y devuelve la cantidad de caracteres escritos.
- `append_write.py`: Añade una cadena de texto al final de un archivo UTF-8 (agrega o crea) y devuelve la cantidad de caracteres añadidos.
