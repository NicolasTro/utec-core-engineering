# Python - Manejo de excepciones

Este directorio contiene ejercicios prácticos sobre manejo de excepciones en Python:
- `safe_print_list.py`: Impresión segura de elementos de una lista sin usar `len()`.
- `safe_print_integer.py`: Impresión segura de enteros utilizando `try: / except:`.
- `safe_print_list_integers.py`: Impresión de enteros contenidos en una lista omitiendo otros tipos.
- `safe_print_division.py`: División segura de enteros con cláusula `finally`.
- `raise_exception.py`: Lanzar excepción de tipo `TypeError`.
- `raise_exception_msg.py`: Lanzar excepción de tipo `NameError` con mensaje personalizado.
