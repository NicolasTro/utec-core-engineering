# Python - Herencia y polimorfismo

Este directorio contiene las soluciones y ejercicios prácticos correspondientes al módulo de Herencia y Polimorfismo en Python:

- `0-polymorphism_demo.py`: Demostración conceptual de herencia y polimorfismo con clases `Animal`, `Dog` y `Cat`.
- `base_geometry.py`: Clase base `BaseGeometry` con validación de enteros `integer_validator()` y método abstracto `area()`.
- `1-rectangle.py`: Clase `Rectangle` que hereda de `BaseGeometry` y valida dimensiones en su inicialización.
- `2-rectangle.py`: Extensión de `Rectangle` con cálculo de área y formato personalizado de impresión `__str__()`.
- `1-square.py`: Clase `Square` que hereda de `Rectangle` con validación de tamaño `size`.
- `2-square.py`: Extensión de `Square` con representación en cadena de texto `__str__()`.
