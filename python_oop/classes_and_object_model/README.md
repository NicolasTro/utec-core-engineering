# Python - Clases y modelo de objetos

Este directorio contiene las soluciones y ejercicios prácticos correspondientes al módulo de Programación Orientada a Objetos en Python (Clases y modelo de objetos):

- `0-square.py`: Definición de una clase vacía `Square`.
- `1-square.py`: Clase `Square` con atributo privado `size`.
- `2-square.py`: Clase `Square` con validación de tipo y valor para `size`.
- `3-square.py`: Clase `Square` con cálculo de área mediante método público `area()`.
- `4-square.py`: Clase `Square` con getters y setters `@property` para acceder y mutar `size`.
- `5-square.py`: Clase `Square` con método `my_print()` para imprimir la figura con el carácter `#`.
- `6-square.py`: Clase `Square` con coordenadas `position`, manejo de desplazamientos y método `__str__()`.
- `1-rectangle.py`: Clase `Rectangle` con ancho y alto validados y protegidos por propiedades.
- `2-rectangle.py`: Clase `Rectangle` con métodos para calcular área y perímetro.
